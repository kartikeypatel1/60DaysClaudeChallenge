# 📖 Overview

Finding the right research funding, understanding technology trends, and tracking innovation opportunities is often scattered across multiple websites and databases.

The AI Research Funding & Innovation Intelligence Platform brings everything together into one intelligent platform by combining AI-powered recommendations, research analytics, patent intelligence, and funding discovery.

The platform enables users to:

- Discover research grants
- Receive personalized funding recommendations
- Track emerging technologies
- Analyze research trends
- Explore patent landscapes
- Monitor innovation ecosystems
- Save and manage opportunities
- Generate AI-powered insights

# ⚙ Installation

## Clone Repository

```bash
git clone <repository-url>

cd research-funding-platform
```

---

## Frontend

```bash
cd client

npm install

npm run dev
```

---

## Backend

```bash
cd server

npm install

npm run dev
```

---

## Environment Variables

Create a `.env` file.

```env
DATABASE_URL=

JWT_SECRET=

GEMINI_API_KEY=

PORT=5000
```
