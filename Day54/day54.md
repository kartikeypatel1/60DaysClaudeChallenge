Implement the first major user-facing feature defined in the approved **10-Day Blueprint**. Build only the functionality scheduled for Day 4 without changing the existing architecture or beginning work planned for later days.

> **Important**

> - Write production-ready code.

> - Complete one milestone at a time and verify each before moving forward.

---

# Working Rules

- Assume the developer is a beginner unless stated otherwise.
- Whenever a manual action is required (installing packages, configuring services, creating accounts, etc.), provide:
  - Exact terminal commands
  - Exact menu/button names
  - Expected output
- Pause after every milestone until it has been tested successfully.
- Never continue on top of broken code.
